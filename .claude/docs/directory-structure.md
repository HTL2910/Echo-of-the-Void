# Directory Structure (Echo of the Void, Unity)

```text
/                                  # Unity project root
├── CLAUDE.md                      # Master configuration for Claude Code
├── .claude/                       # Agents, skills, hooks, rules, docs (from claude-code-game-studios; see CCGS-SOURCE.md)
├── Assets/
│   ├── Scripts/                   # C# runtime (Player, Core, UI, Save, Settings, Feedback, Environment | Enemies, Bosses, Combat, Environment/Mechanics)
│   ├── Editor/                    # SceneGenerator, prefab builders (Codex/ = Codex's)
│   ├── Tests/PlayMode/            # NUnit PlayMode tests
│   ├── Art/ Audio/ Fonts/         # Content (Anti)
│   ├── Prefabs/ Scenes/           # Prefabs (Player, Enemies, Bosses, Mechanics, Environment, VFX, Levels), scenes
│   └── Settings/                  # ScriptableObject data (Enemies/...)
├── Docs/                          # ALL documentation (capital D; macOS is case-insensitive, so `docs/` in skill text = this folder)
│   ├── trang_thai_hien_tai.md     # START HERE: status, commands, gotchas
│   ├── echo_of_the_void_master_spec.md   # the design (GDD) and decision log
│   ├── ke_hoach_den_100.md, tich_hop.md, task_*.md, ban_giao/, yeu_cau_*.md   # planning and handoffs
│   ├── engine-reference/unity/    # version-pinned Unity API notes (from the studio template)
│   └── architecture/              # ADRs (/architecture-decision)
├── design/                        # OPTIONAL: GDDs generated by /design-system (design/gdd, design/narrative)
├── production/                    # Studio-skill state: stage.txt, review-mode.txt, sprints, milestones
│   ├── session-state/             # ephemeral (gitignored)
│   └── session-logs/              # audit trail (gitignored)
├── prototypes/                    # throwaway prototypes (outside Assets/, never imported by Unity)
├── Tools/                         # run_tests_isolated.sh, check_ownership.py
├── Packages/  ProjectSettings/    # Unity configuration (Claude owns)
```

Mapping from the template's names: `src/` → `Assets/Scripts/`, `assets/` → `Assets/`, `tests/` → `Assets/Tests/`, `docs/` → `Docs/`, `tools/` → `Tools/`.
The game's own design documents are the Vietnamese files in `Docs/`; `design/` is only used if you run the studio design skills.
